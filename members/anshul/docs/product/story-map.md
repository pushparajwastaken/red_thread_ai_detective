# User story map

Journey →           Start case | Explore | Question | Present | Connect | Accuse | Reflect
MVP1 vertical slice  Load case  | Clues   | B1/C*    | Evidence| Board   | A3/F3  | Report
MVP2 extension       3 cases    | Links   | Agents   | Bluff   | Graph   | Thread | Compare
MVP3 hardening       Chapters   | Audit   | Guards   | Audit   | Trace   | Reveal | Ablations

*The presentation's B/C IDs describe planned backlog work. The repository
already has a simpler bounded interrogation path; do not mark the entire
presentation story complete based on that path alone.

Epics:
E1 Fair, solvable case — A1, A2, A3.
E2 Bounded characters and conversation — B1–B3, C1–C3, D1–D3, E1.
E3 Player investigation — F1–F3.
E4 Evidence and evaluation — G1–G4.
E5 Cross-case orchestration — H1–H7, REL2.
E6 Hardening and final release — H8–H12, REL3.

Slicing rule: Each release must permit a player to complete an investigation;
do not call an isolated component an MVP.
